# Ubuntu Innovations IT Support Capstone Project

## Project Overview

This project focuses on designing and implementing a complete IT infrastructure and support solution for Ubuntu Innovations (Pty) Ltd, a fictional technology company based in Cape Town, South Africa.

The project forms part of the Google IT Support Professional Certificate Capstone Project and covers:

- Technical support fundamentals
- Networking
- Operating systems administration
- Cybersecurity
- Backup and disaster recovery
- IT troubleshooting
- Professional documentation

The goal of the project is to design a secure, scalable, and efficient IT environment suitable for a modern business with 25 employees.

Total Employees: 25

## Project Objectives

The objectives of this project are to:

- Analyse business and technical requirements
- Recommend hardware and software solutions
- Design a secure network infrastructure
- Develop cybersecurity policies
- Create backup and disaster recovery plans
- Produce troubleshooting documentation
- Demonstrate IT support and system administration skills
