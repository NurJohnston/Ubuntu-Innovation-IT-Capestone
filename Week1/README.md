# Week 1 – Technical Support Fundamentals and Networking Basics

## Week 1 Objective

The objective of Week 1 is to analyse the company requirements and develop foundational infrastructure documentation for the organization.

## Week 1 Tasks

### Task 1: Business Requirements Analysis
- Analyse company requirements
- Identify security and connectivity needs
- Document operational challenges

### Task 2: Hardware Inventory
- Recommend hardware devices
- Justify hardware specifications

### Task 3: Software Inventory
- Recommend software for each department

### Task 4: Initial Network Diagram
- Create a high-level network topology

### Task 5: Troubleshooting Scenarios
- Document common IT support problems and solutions

---

## Week 1 Deliverables

- Business Requirements Analysis
- Hardware Inventory
- Software Inventory
- Network Diagram
- Troubleshooting Log
